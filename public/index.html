A/B टेस्टिंग (`Old_Design`)

की-नेम Old_Design: true होने पर मूल ओल्ड UI तथा false होने पर नया प्रीमियम UI/UX बिना रीस्टार्ट रियल-टाइम लोड होता है।

⚡

100% Clean Architecture

Kotlin, Jetpack Compose, Material 3, Hilt Dependency Injection, Room Local Database, Coroutines, StateFlow, और DataStore Preferences।

A/B Testing Implementation

Key Name: `Old_Design`

एप्लिकेशन में A/B टेस्टिंग कॉन्फ़िगरेशन पूर्णतः एकीकृत है। सेटिंग्स स्क्रीन से या रिमोट कॉन्फ़िग से जब Old_Design = true होगा तो मूल ओल्ड डिज़ाइन दिखेगा, और जब Old_Design = false होगा तो आधुनिक नया UI/UX दिखेगा।

Old_Design = true
Original minimal cards, old calendar grid & classic dialogs
Old_Design = false (Default)
Elevated Vedic cards, astronomical widget, filter chips & M3 tokens
